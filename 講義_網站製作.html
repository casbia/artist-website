Chapter 01

認識 HTML5：網頁的骨架

HTML（HyperText Markup Language）是網頁的骨架。就像蓋房子先搭鋼骨，HTML 定義了網頁有哪些「盒子」，這些盒子叫什麼、放什麼內容。CSS 再負責讓盒子好看，JavaScript 讓它會動。

1-1 每個 HTML 頁面的必要結構

每一個 HTML 檔案都必須從以下骨架開始：

<!-- 告訴瀏覽器這是 HTML5 -->
<!DOCTYPE html>

<!-- lang：告訴搜尋引擎和螢幕閱讀器這是繁體中文 -->
<html lang="zh-Hant-TW">
<head>
  <!-- 設定文字編碼（支援中文必須有）-->
  <meta charset="UTF-8">
  <!-- 讓網頁在手機上也能正常縮放（RWD 必須有）-->
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>頁面標題（出現在瀏覽器分頁）</title>
  <link rel="stylesheet" href="css/style.css">
</head>
<body>
  <!-- 所有看得見的內容都放在 body 裡 -->
</body>
</html>
HTML 的 <head> 是「給瀏覽器看的」（設定、CSS引用、meta 資訊）。<body> 是「給使用者看的」（所有出現在頁面上的內容）。

1-2 HTML5 語意化標籤

HTML5 引入了語意化標籤，讓每個區塊的「意義」更清楚。龍蝦俠網站的每個頁面都使用這個結構：

標籤語意龍蝦俠網站用途
<header>頁首固定導覽列（含 Logo + 選單）
<nav>導覽頁面連結列表
<main>主要內容每頁的核心區塊
<section>章節區塊Hero / 作品集 / 關於…等各區
<article>獨立文章每一件作品卡片
<aside>側邊補充聯絡頁的資訊欄
<footer>頁尾版權 + 社群連結
<body>
  <header class="site-header">
    <nav>...</nav>
  </header>

  <main>
    <section class="hero">...</section>
    <section class="about-preview">...</section>
  </main>

  <footer class="site-footer">...</footer>
</body>

Chapter 02

CSS3 基礎：視覺設計系統

CSS（Cascading Style Sheets）負責控制 HTML 盒子的外觀：顏色、尺寸、位置、動畫。龍蝦俠網站把所有設計決策集中在 variables.css 裡，透過 CSS Custom Properties（變數）統一管理。

2-1 CSS 引用順序（非常重要！）

CSS 引用順序決定了「後面的樣式會覆蓋前面的」。龍蝦俠網站規定的引用順序絕不能改變。
<!-- 1. 先引入歸零：消除所有瀏覽器預設樣式 -->
<link rel="stylesheet" href="css/reset.css">

<!-- 2. 再引入設計變數：定義色彩、字體、間距 -->
<link rel="stylesheet" href="css/variables.css">

<!-- 3. 再引入共用樣式：導覽列、頁尾、按鈕等 -->
<link rel="stylesheet" href="css/style.css">

2-2 CSS 變數系統（variables.css）

CSS Custom Properties（俗稱 CSS 變數）讓我們把「設計決策」統一放在 :root 裡。改一個地方，整個網站同步更新。

/* 在 :root 裡定義變數，整個頁面都能用 */
:root {
  /* 語法：--變數名稱: 值; */
  --color-bg:     #0a0a0a;   /* 主背景色 */
  --color-accent: #ff4500;   /* 強調色（龍蝦橘紅）*/
  --color-text:   #f0f0f0;   /* 主文字色 */
  --font-heading: 'Playfair Display', serif;
  --space-4:      3.2rem;     /* 32px 間距 */
}

/* 使用變數：用 var() 函式 */
.hero-title {
  color: var(--color-accent);
  font-family: var(--font-heading);
  margin-bottom: var(--space-4);
}
想要換整個網站的主色調？只要修改 variables.css 裡的 --color-accent 一個地方就好！

2-3 CSS Transitions 過渡動畫

讓 hover 效果不是瞬間跳變，而是平滑過渡：

.btn {
  background-color: var(--color-accent);
  /* transition：屬性 時間 緩動函式 */
  transition: background-color 0.3s ease,
              transform 0.3s ease;
}

.btn:hover {
  background-color: #cc3600;
  transform: translateY(-2px); /* 上浮 2px */
}

2-4 CSS @keyframes 關鍵幀動畫

比 transition 更強大，可以定義動畫的任意中間狀態：

/* 定義動畫：from（開始）→ to（結束）*/
@keyframes fadeInUp {
  from { opacity: 0; transform: translateY(30px); }
  to   { opacity: 1; transform: translateY(0); }
}

/* 套用動畫：animation: 名稱 時間 緩動 延遲 次數 */
.hero-name {
  animation: fadeInUp 0.8s ease 0.5s both;
  /* both：動畫前保持 from 狀態，結束後保持 to 狀態 */
}

Chapter 03

CSS3 進階：Flexbox 與 Grid 排版

現代 CSS 排版有兩個強大工具：Flexbox（一維排列）和 CSS Grid（二維格狀）。龍蝦俠網站大量使用這兩種技術。

3-1 Flexbox 一維排列

Flexbox 適合用於「一排」的元素排列，例如導覽列、按鈕群組、卡片行。

/* 父元素：設為 flex 容器 */
.nav-container {
  display: flex;
  align-items: center;      /* 垂直置中 */
  justify-content: space-between; /* 兩端對齊 */
  gap: 2.4rem;              /* 子元素間距 */
}

/* flex: 1 讓元素佔滿剩餘空間 */
.nav-links { flex: 1; }

/* flex-shrink: 0 讓元素不縮小 */
.nav-logo { flex-shrink: 0; }
屬性常用值效果
justify-contentflex-start / center / flex-end / space-between主軸對齊（水平）
align-itemsflex-start / center / flex-end / stretch交叉軸對齊（垂直）
flex-directionrow / column排列方向（橫/直）
flex-wrapnowrap / wrap是否允許換行
gap任意長度子元素間距

3-2 CSS Grid 二維格狀

Grid 適合製作複雜的二維版面，例如作品牆、雜誌版面。

/* 作品牆：自動計算欄數 */
.works-grid {
  display: grid;

  /* 魔法語法：auto-fill + minmax
     auto-fill：自動算能排幾欄
     minmax(300px, 1fr)：每欄最小300px，最大均分 */
  grid-template-columns: repeat(auto-fill, minmax(300px, 1fr));
  gap: 2.4rem;
}

/* 某張卡片跨 2 欄 */
.featured-card:first-child {
  grid-column: 1 / 3; /* 從第1欄線到第3欄線 */
}
auto-fill + minmax 是響應式設計的神器。不需要寫任何 media query，版面會自動根據螢幕寬度決定幾欄！

3-3 響應式設計（RWD）Media Query

/* 預設：桌機版（大螢幕先寫）*/
.contact-grid {
  display: grid;
  grid-template-columns: 1fr 2fr; /* 左1:右2 */
}

/* 768px 以下（手機）：改成單欄 */
@media (max-width: 768px) {
  .contact-grid {
    grid-template-columns: 1fr; /* 單欄 */
  }
}

Chapter 04

JavaScript：讓頁面活起來

JavaScript 讓 HTML+CSS 的靜態網頁變得有互動性。龍蝦俠網站的 js/main.js 裡集中了六個功能模組。

4-1 DOM 操作基礎

DOM（Document Object Model）是瀏覽器把 HTML 轉換成的樹狀結構，JavaScript 可以透過它選取和修改元素。

/* 選取元素 */
const btn  = document.querySelector('.btn');       // 選第一個
const btns = document.querySelectorAll('.btn');    // 選全部

/* 修改 class */
btn.classList.add('active');      // 加 class
btn.classList.remove('active');   // 移除 class
btn.classList.toggle('open');    // 有就移除，沒有就加

/* 監聽事件 */
btn.addEventListener('click', function() {
  console.log('按鈕被按了！');
});

/* 讀取自訂 data-* 屬性 */
// <button data-filter="generative">
const filter = btn.getAttribute('data-filter'); // 'generative'

4-2 IntersectionObserver 滾動進場動畫

這是 main.js 最重要的功能之一。當元素進入視窗時自動觸發動畫：

Step 1

在 HTML 元素加上 class="reveal"

<h2 class="reveal">進入視窗才顯現的標題</h2>
<p class="reveal reveal-delay-2">延遲 200ms 出現</p>
Step 2

CSS 定義初始（隱藏）和可見狀態

/* 初始狀態：隱藏 + 往下偏移 30px */
.reveal {
  opacity: 0;
  transform: translateY(30px);
  transition: opacity 0.6s ease, transform 0.6s ease;
}

/* 可見狀態：JS 加上 .visible class 後觸發 */
.reveal.visible {
  opacity: 1;
  transform: translateY(0);
}
Step 3

JS 用 IntersectionObserver 監看元素，進入視窗就加 .visible

const observer = new IntersectionObserver(
  function(entries) {
    entries.forEach(function(entry) {
      if (entry.isIntersecting) {
        entry.target.classList.add('visible');
      }
    });
  },
  { threshold: 0.15 } // 出現 15% 時觸發
);

document.querySelectorAll('.reveal').forEach(el =>
  observer.observe(el)
);

4-3 Nav 雙模式：scroll 偵測 + hero-mode（index.html 首頁）

首頁的 Hero section 是全螢幕影片背景（暗色調），nav 預設的淡色背景+深色文字會讓人看不清楚。
解法：偵測使用者是否還在 Hero 範圍內，動態切換兩套 nav 樣式。

原理

用 scrollY 判斷是否在 Hero 範圍，JS 切換 CSS class

const header      = document.querySelector('.site-header');
const heroSection = document.getElementById('hero');  // 只在首頁存在

// 首頁初始：直接設定 hero-mode
if (heroSection) header.classList.add('hero-mode');

window.addEventListener('scroll', function() {

  // 通用：捲超過 50px → 加深背景
  if (window.scrollY > 50) {
    header.classList.add('scrolled');
  } else {
    header.classList.remove('scrolled');
  }

  // 首頁專用：在 Hero 範圍內 → hero-mode（白字透明底）
  if (heroSection) {
    if (window.scrollY < heroSection.offsetHeight - 80) {
      header.classList.add('hero-mode');
    } else {
      header.classList.remove('hero-mode'); // 恢復淡色主題
    }
  }

}, { passive: true });
CSS

style.css：.hero-mode 的兩 class 選擇器優先級 > .scrolled

/* .hero-mode + .scrolled 雙 class → 優先級高於單一 .scrolled */
.site-header.hero-mode,
.site-header.hero-mode.scrolled {
  background-color: rgba(0, 0, 0, 0.22); /* 透明深色底 */
  backdrop-filter: blur(8px);
}

.site-header.hero-mode .nav-logo,
.site-header.hero-mode .nav-links a {
  color: rgba(255, 255, 255, 0.9);  /* 白色文字 */
}
三種狀態一目了然：
① 首頁 Hero 頂端：.hero-mode → 透明底 + 白字
② 首頁往下捲（還在 Hero 範圍）：.hero-mode.scrolled → 仍白字（hero-mode 優先）
③ 捲出 Hero 後所有頁面：.scrolled（或無 class）→ 淡色底 + 深色字

Chapter 05

p5.js：生成藝術整合

p5.js 是一個讓藝術家也能輕鬆使用的 JavaScript 繪圖庫。龍蝦俠網站使用四種整合模式，從課堂練習的 p5.js_with_html 資料夾出發，逐步擴展。

5-1 p5.js Instance Mode（網頁整合的正確方式）

課堂練習用的 Global Mode（直接寫 function setup()）方便學習，但在有其他 JavaScript 的網頁中容易衝突。Instance Mode 把所有 p5 功能封裝在一個函式裡，是網頁整合的標準做法。
<!-- 1. 引入 p5.js CDN（放在 </body> 前）-->
<script src="https://cdnjs.cloudflare.com/ajax/libs/p5.js/1.9.0/p5.min.js"></script>

<!-- 2. 指定 canvas 要放進的 div 容器 -->
<div id="my-canvas"></div>
// Instance Mode 語法
new p5(function(p) {

  // 所有 p5 功能都透過 p. 存取
  p.setup = function() {
    let canvas = p.createCanvas(400, 400);
    canvas.parent('my-canvas'); // 放進指定 div
  };

  p.draw = function() {
    p.background(15);
    p.fill(255, 69, 0);
    p.ellipse(p.mouseX, p.mouseY, 20);
  };

}, 'my-canvas'); // 第二個參數也可以直接指定容器
⚠️ CSS canvas 尺寸陷阱：圓形變橢圓
p5 canvas 有固定的像素解析度（例如 520×460）。
若在 CSS 設 canvas { width: 100%; }，只改變「顯示大小」， 不改變「內部解析度」，導致所有圓形被拉成橢圓！

正確做法：
canvas { max-width: 100%; } — 可縮小但不拉伸
搭配容器 display: flex; align-items: center; 讓 canvas 置中。

5-2 calling-p5-js-from-javascript（按鈕控制 p5）

來自 p5.js_with_html/4 練習的進階版：HTML 按鈕可以呼叫 p5 sketch 內部的函式。
在 interactive.html 的「00b 區塊」可以看到完整示範（p5/demo-js-to-p5.js）。

// ① sketch 內部：建立「對外接口物件」
const shapeCtrl = {}; // 在 new p5() 之前宣告！

new p5(function(p) {
  let currentShape = 'circle';

  p.setup = function() { p.createCanvas(480, 400); };
  p.draw  = function() { /* 繪製 currentShape ... */ };

  // ② 把函式掛到接口物件上（HTML 按鈕可見）
  shapeCtrl.nextShape = function() {
    currentShape = 'square'; // 修改 sketch 內部變數
  };

  shapeCtrl.setColor = function(hex) {
    currentColor = hex;        // 接受 HTML 按鈕傳入的參數
  };

  shapeCtrl.clear = function() {
    shapes = [];               // 清空畫布上的形狀
  };

}, 'jtop5-canvas'); // 掛到 HTML 容器
<!-- ③ HTML 按鈕：onclick 直接呼叫接口物件的函式 -->
<button onclick="shapeCtrl.nextShape()">切換形狀</button>
<button onclick="shapeCtrl.setColor('#1a2980')">深藍</button>
<button onclick="shapeCtrl.setSize(80)">大</button>
<button onclick="shapeCtrl.clear()">清空</button>
關鍵原則：接口物件（shapeCtrl）必須在 new p5() 之前宣告，才能讓 HTML 找到它。各 sketch 的接口物件不同（如 mouseDraw、keyboardArt、webgl3d、shapeCtrl）。

5-2b calling-javascript-from-p5-js（p5 呼叫 JS 更新 DOM）

反向模式：p5 sketch 內部的事件（碰壁、碰撞、滑鼠位置）呼叫外部 JavaScript 函式，即時更新 HTML 元素。
在 interactive.html 的「00 區塊」可以看到完整示範（p5/interactive-p5-to-js.js）。

// ① 在 new p5() 之外定義「要被呼叫的」JS 函式
function onBallHitWall() {
  // 更新 HTML 元素（DOM 操作）
  const el = document.getElementById('wall-count');
  el.textContent = ++wallHits;
}

new p5(function(p) {
  p.draw = function() {
    // ② p5 內部事件觸發 → 呼叫外部函式
    if (ball.x < 0) {
      ball.vx *= -1;
      onBallHitWall(); // ← 直接呼叫外部函式！
    }
  };
});
<!-- ③ HTML：靜態等待被更新的元素 -->
<div id="wall-count">0</div>
這兩個模式是「雙向通訊」：
p5 → JS（calling-js-from-p5）：p5 事件更新 HTML 顯示
JS → p5（calling-p5-from-js）：HTML 按鈕控制 sketch 行為

5-3 3D WebGL 模式

p.setup = function() {
  // 第三個參數 WEBGL：啟用 3D 模式！
  p.createCanvas(560, 420, p.WEBGL);
};

p.draw = function() {
  p.background(15);
  p.directionalLight(255, 80, 30, 1, -1, -1); // 方向光
  p.specularMaterial(240, 90, 40);             // 金屬材質
  p.rotateY(p.frameCount * 0.01);               // 每幀旋轉
  p.box(100);                                    // 畫正方體
};

6-3 測試與除錯

每次修改後，按 F12（或右鍵→「檢查」）開啟瀏覽器開發者工具：
  • Console 標籤：查看 JavaScript 錯誤（紅色文字）
  • Elements 標籤：即時看到 HTML 結構和 CSS 效果
  • Network 標籤：確認 CSS / JS / 圖片是否正確載入
